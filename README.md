# 投資學期中考刷題

線上使用：https://breitiling0830.github.io/investment-quiz/

依提供的「夜四技 習作複習 題庫1.pdf」與財管刷題 HTML 範例製作。

- 41 題是非：依講義 O／X 即時判分、附解析。
- 7 題計算與申論：草稿自動儲存，對照參考答案自行評估。
- 主題分組、隨機抽題、錯題複習、搜尋、公式速查。
- 本機作答紀錄與練習進度，支援中斷後繼續。
- 手機與深色模式；單一 HTML，無外部套件依賴。

## 題庫整理

保留原題號與 PDF 頁碼，常見擷取錯字已整理。主題分組由工具新增，並非原書章節。原講義部分論述有簡化或疑義（如 β 與 SML 斜率、百分比單位），仍依原講義答案判分，補充說明另列；第 38 題保留原表格。申論補充整理並非教師唯一標準答案。

## 使用

直接開啟 index.html，或使用 GitHub Pages。紀錄保存在目前瀏覽器的 localStorage，不會傳送到伺服器；請勿將其視為跨裝置同步。清除網站資料可能遺失紀錄。

## GitHub Pages

Settings → Pages → Deploy from a branch → main → / (root) → Save。
